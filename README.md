# 8x32 LED Banner Programmer

This project documents how to drive an 8×32 MAX7219 serial LED matrix from an ESP32-S3 in the Arduino IDE and includes a helper Python script to generate scrolling banner text assets.

## Hardware

- **Matrix:** 8×32 (four MAX7219 modules chained).
- **Controller:** ESP32-S3 (Arduino core 2.x or newer).
- **Power:** 5 V supply capable of ~2 A for full brightness.
- **Signal level:** The MAX7219 accepts 3.3 V logic, so level shifting is optional when wiring directly to an ESP32-S3.

### Wiring (ESP32-S3 to MAX7219 chain)

| Matrix pin | ESP32-S3 pin (example) | Notes |
| --- | --- | --- |
| VCC | 5 V | Use external 5 V supply for stability. |
| GND | GND | Common ground between matrix and ESP32-S3. |
| DIN | GPIO 23 (MOSI) | Data line. |
| CS | GPIO 5 | Chip-select / load. |
| CLK | GPIO 18 (SCK) | Clock line. |

The pins above match the sample sketch; change them in code if you wire differently.

## Arduino sketch

The sketch below uses the [MD_Parola](https://github.com/MajicDesigns/MD_Parola) and [MD_MAX72XX](https://github.com/MajicDesigns/MD_MAX72XX) libraries. Install them via **Tools → Manage Libraries…** in the Arduino IDE.

```cpp
#include <MD_Parola.h>
#include <MD_MAX72xx.h>
#include <SPI.h>

#define HARDWARE_TYPE MD_MAX72XX::FC16_HW
#define MAX_DEVICES 4  // 4 × 8×8 modules = 32 columns
#define CLK_PIN 18
#define DATA_PIN 23
#define CS_PIN 5

MD_Parola parola(HARDWARE_TYPE, DATA_PIN, CLK_PIN, CS_PIN, MAX_DEVICES);

// This header is generated by tools/make_banner.py
#include "messages.h"

uint8_t currentMessage = 0;
const textEffect_t scrollEffect = PA_SCROLL_LEFT;

void setup() {
  parola.begin();
  parola.setIntensity(DISPLAY_INTENSITY);
  parola.displayText(messages[currentMessage], scrollEffect, SCROLL_SPEED, 0, scrollEffect, scrollEffect);
}

void loop() {
  if (parola.displayAnimate()) {
    currentMessage = (currentMessage + 1) % MESSAGE_COUNT;
    parola.displayText(messages[currentMessage], scrollEffect, SCROLL_SPEED, 0, scrollEffect, scrollEffect);
  }
}
```

### Build steps

1. Install the ESP32 boards package in the Arduino IDE (Board Manager → `esp32` by Espressif).
2. Install **MD_Parola** and **MD_MAX72XX** libraries.
3. Create `messages.h` with the Python helper (below) or edit the sample manually (it also stores `SCROLL_SPEED` and `DISPLAY_INTENSITY`).
4. Select your ESP32-S3 board and serial port, then upload the sketch.

## Python helper: tools/make_banner.py

This script emits a `messages.h` header containing your scrolling text along with `SCROLL_SPEED` and `DISPLAY_INTENSITY` constants. It escapes characters for safe inclusion in the Arduino sketch and can be checked into your project alongside `main.ino`.

Usage examples:

```bash
python tools/make_banner.py "Hello, world!" "Visit example.com" > messages.h
python tools/make_banner.py --speed 40 --intensity 3 "Line 1" "Line 2" > messages.h
```

Include the resulting `messages.h` in your Arduino sketch directory. Re-run the script whenever you want to change the banner text.

## Troubleshooting tips

- If nothing lights up, verify `CS`, `CLK`, and `DIN` wiring order—CS and CLK are easy to swap accidentally.
- Power the matrix from 5 V; USB power alone can be marginal at full brightness.
- If characters appear mirrored or garbled, set `HARDWARE_TYPE` to match your modules (`FC16_HW` and `PAROLA_HW` are common options in MD_MAX72XX).
- Increase `scrollSpeed` (higher number) if the text moves too quickly; decrease it for faster motion.
